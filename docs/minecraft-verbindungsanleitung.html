🎮 Minecraft Server – Verbindungsanleitung

Hier erfahrt ihr, wie ihr unserem Minecraft-Server beitreten könnt – sowohl mit der Java Edition als auch mit der Bedrock Edition.

🖥️ Java Edition (PC) – Tailscale

Für Java-Spieler nutzen wir Tailscale, damit ihr euch sicher mit dem Server verbinden könnt.

Schritt 1 – Tailscale installieren

  1. Ladet euch Tailscale herunter: https://tailscale.com/download
  2. Installiert das Programm und meldet euch mit eurem eigenen Account an.
  3. Aktiviert Tailscale.

Schritt 2 – Netzwerk beitreten

  1. Öffnet den Tailscale-Einladungslink, den ihr von mir bekommt.
  2. Akzeptiert die Einladung.
  3. Stellt sicher, dass Tailscale verbunden ist.

Schritt 3 – Minecraft beitreten

  1. Startet Minecraft Java Edition.
  2. Geht auf Mehrspieler → Server hinzufügen.
  3. Gebt folgende Serveradresse ein:
    SERVER-TAILSCALE-IP:25565
  4. Speichern, verbinden und losspielen! ✅

📱🎮 Bedrock Edition (PlayStation / Xbox / Switch)

Da Konsolen normalerweise keine eigenen Server hinzufügen können, nutzen wir die kostenlose BedrockConnect-App auf dem Smartphone.

Schritt 1 – BedrockConnect einrichten

  1. Installiert die BedrockConnect-App auf eurem Smartphone (Android oder iOS).
  2. Verbindet Smartphone und Konsole mit demselben WLAN.
  3. Öffnet die App und wechselt zu Custom → +.
  4. Tragt folgende Daten ein:
    • Name: Minecraft Server
    • IP: SERVER-PUBLIC-IP
    • Port: 19132
  5. Speichert den Server.

Schritt 2 – Verbindung starten

  1. Wählt euren Server in der App aus.
  2. Tippt auf Start (kostenlos ggf. nach Werbung).
  3. Startet Minecraft Bedrock auf eurer Konsole.
  4. Geht zu Spielen → Welten bzw. Freunde.
  5. Der Server sollte dort als LAN-Welt auftauchen.
  6. Wählt ihn aus und verbindet euch! ✅

💡 Wichtig:

  • Für BedrockConnect benötigt ihr kein Tailscale und müsst keine DNS-Einstellungen ändern.
  • Auf Konsolen ist ein aktives Online-Abonnement erforderlich.
  • Falls der Server nicht erscheint, prüft, ob Smartphone und Konsole im gleichen Netzwerk sind.
  • Ihr müsst auf der Whitelist stehen. Schickt dafür euren Minecraft-Namen in #whitelist-add.

Bei Problemen schreibt einfach in den Discord – wir helfen euch! 🚀

Noch wichtig für dein Setup auf dem Raspberry Pi:

  • Ersetze SERVER-TAILSCALE-IP durch die Tailscale-IP deines Pis und SERVER-PUBLIC-IP durch deine öffentliche IP bzw. Domain.
  • Für Bedrock-Spieler auf Windows oder Smartphone reicht Spielen → Server → Server hinzufügen mit der öffentlichen IP und Port 19132. BedrockConnect ist dafür nicht nötig.
  • Da du Geyser mit transport: nethernet verwendest, müssen am Router TCP und UDP auf Port 19132 freigegeben sein. Andernfalls kann BedrockConnect deinen Server als offline anzeigen.
  • Für Tailscale empfehle ich, nur deinen Raspberry Pi über die Funktion Share freizugeben, statt Freunden Zugriff auf dein gesamtes Tailnet zu geben.
